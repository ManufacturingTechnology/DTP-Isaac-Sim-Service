The [AMT](https://amtonline.org/) Digital Testbed Platform (DTP)
is a collection of modular services which facilitate developing, testing, and validating manufacturing technologies,
methods, and ideas. This service is intended to aid in developing, running, and deploying digital testbeds built on 
[NVIDIA Isaac Sim](https://developer.nvidia.com/isaac/sim).

## Documentation

Online documentation can be found at [https://iss.amt.onl/](https://iss.amt.onl/).
